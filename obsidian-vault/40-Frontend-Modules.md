# Frontend Modules
## Main Page

- `SolutionArchitectProposalPage.js`
  - paste or upload requirement text
  - run analysis
  - review extracted JSON
  - review clarification questions
  - generate the proposal draft
  - export PPTX from the selected template

## UX Notes

- This is a single-purpose proposal workflow.
- The UI is meant to support demoing the whole flow without switching to unrelated pages.
- The sample input is generic so it does not push the app toward any specific cloud vendor.
